# Changelog

## Unreleased

- open items are grouped by section, in the same order as the Bring! app; the section order can be changed in the settings

## Version 2.3.0

- UI changes:
  - The list header now shows the name of your Bring list
  - The current time is always shown at the top of the screen

## Version 2.2.0

- item icons now match the sections of your Bring! list, so more items get a fitting icon
- item details (like "2 kg" or "organic") are shown below the item name
- refresh your list at any time by long-pressing the select button
- new setting to turn off touch input on touchscreen watches
- more reliable syncing with fewer unnecessary retries and logins

## Version 2.1.0

- new and improved settings page
- more compact UI on the watch shows more items on the screen
- long items on your shopping list are no longer cut off, they now scroll through the screen when highlighted

## Version 2.0.1

- fixed a bug on Pebble Classic that prevented the app from syncing

## Version 2.0.0

First release of Brebble!, a fork of aioras' Bring! app.

What's Changed

- Add English default and multi-language support following the watch language
- Strip trailing punctuation added by voice dictation
